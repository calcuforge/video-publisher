# 标题点击率优化指南（Title Guide）

> **何时加载：** 物料数据生成步骤中编写/审核 `materials.yaml` 的 title 字段，
> 或配置 `project_config.yaml` 的 `publish_defaults.title_format` 时。
> 目的：发布标题也要**吸引点击**，而非平铺直叙的主题名。

## 标题吸引力公式

标题 = 主题 + 一个吸引点击的理由。常用手法（按视频类型选择 1-2 个组合）：

| 手法 | 示例（主题：GPU架构详解） | 适用类型 |
|------|--------------------------|---------|
| **悬念/好奇缺口** | "GPU架构70年，为什么只有英伟达赢了？" | 科普/纪录片 |
| **数字/具体化** | "GPU架构详解：5个你从没听说过的设计细节" | 知识/评测 |
| **结果承诺** | "看完这篇GPU架构详解，你也能设计芯片" | 教程 |
| **情绪词** | "GPU架构被严重低估的真相" | 观点/评论 |
| **对比/冲突** | "CPU vs GPU：架构之争决定了AI的生死" | 热点/对比 |
| **时间/时效** | "2026年GPU架构深度解析（附避坑指南）" | 评测/导购 |
| **反问** | "你真的了解GPU架构吗？" | 知识 |

**不要**：只写主题名（"GPU架构详解"）、标题党与内容不符（点击高但完播低，
平台会限流）、无意义词堆砌。

## 标题来源与执行方式

标题取值的优先级（`generate_material.py` resolve_title）：
1. **配置了 `title_format`**（非默认 `{video_name}`）→ 渲染模板，
   可引用 `{topic}`（如 `"{topic}：5个你从没听说过的细节"`）；
2. 未配置模板但提供 `video_config`（explainer 联动）→ 直接用 `topic`
   （**仅作基线**，agent 应在物料阶段按本指南优化标题）；
3. 兜底 → `{video_name}`。

**agent 的执行责任**（auto/manual 模式都适用）：
- **auto 模式**：把吸引点击的标题模板写入 `publish_defaults.title_format`
  （引用 `{topic}`），或在物料生成后直接编辑 `materials.yaml` 的 title
  字段——两种方式任选，但**默认模板值 `{video_name}`/裸 topic 不是最终
  标题**，agent 必须至少套用一次吸引力手法；
- **manual 模式**：物料审核点（确认点 #2）向用户展示优化后的标题与备选，
  用户确认/修改后继续。

## 长度与平台差异

| 平台 | 标题长度建议 | 风格 |
|------|-------------|------|
| B站 | 15-30 字（上限 80） | 悬念/数字/情绪，分区调性一致 |
| 抖音 | 15-25 字 + 可带话题词 | 口语化、情绪钩子、前 5 字决定是否点开 |
| 微信视频号 | 10-25 字 | 朋友圈语境：亲近、共鸣、熟人推荐感 |
| youtube | 60-70 字符（SEO 关键词前置） | 关键词开头 + 点击动机，首屏不被截断 |

- 平台上限在 `platform_config.yaml` 的 `material_structure.fields.title.max_length`；
- 中文平台文案用中文，youtube 用英文（或按目标受众语言）。

## 检查清单（agent 审核标题时）

1. 标题 = 主题 + 吸引点击的理由（悬念/数字/承诺/情绪/对比，至少一种）？
2. 内容与视频实际内容一致（不标题党）？
3. 长度符合平台建议与 max_length？
4. 是否避开了纯主题名、无意义堆砌？
5. manual 模式下是否已向用户展示标题与备选？
